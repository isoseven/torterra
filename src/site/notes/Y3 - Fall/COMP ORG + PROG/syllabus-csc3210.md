# 🖥️ TLDR
- **CSC 3210** = Computer Organization and Programming (COP) — understanding the detailed internals of a computer, how software and hardware interact
	- motivating question: when you write `a = 3`, what does the hardware actually see?
- course teaches **RISC-V assembly** (a low-level language): very powerful, close to machine language, direct access to hardware
- **learning objectives**: explain core COP concepts and major processor components (registers, ALU, control unit, etc.) to someone without a CS background; describe how RISC-V assembly instructions interact with the processor and memory; apply RISC-V syntax to solve problems; develop/test/debug RISC-V programs (mostly in labs, not lecture)

## Why This Class Matters
- COP is about understanding the detailed internals of a computer — the interaction between software and hardware
	- motivating question: when we say `a = 3`, what does the hardware see?

## What is RISC-V Assembly?
- very powerful
- close to machine language
- gives direct access to hardware

## Course Learning Objectives
- explain fundamental concepts of COP
- explain the organization and functions of major processor components — registers, ALU, control unit, etc. — in a way someone without a CS background could follow
- describe how RISC-V assembly instructions interact with processor components and memory
- apply RISC-V assembly syntax and programming constructs to solve problems
- develop, test, and debug RISC-V assembly programs
	- this mostly happens in labs, not lecture
